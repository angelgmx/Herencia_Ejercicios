#📚 Contenido 

Ejercicios básicos y avanzados de herencia simple y múltiple (interfaces).
Código comentado paso a paso para entender la lógica detrás de cada solución.
Ejemplos de:

- Creación de clases base y derivadas.
- Uso de extends e implements.
- Sobrescritura de métodos (@Override).
- Clases abstractas y métodos abstractos.
- Jerarquías de clases (ej: Animal → Mamífero → Perro).

🛠️ Tecnologías
Lenguaje: Java 11+.

Herramientas: IntelliJ IDEA, Eclipse o cualquier IDE compatible.

🎯 Objetivos
- Aprender a diseñar jerarquías de clases eficientes.
- Entender cómo reutilizar código mediante la herencia.
- Evitar errores comunes (ej: acoplamiento excesivo).
